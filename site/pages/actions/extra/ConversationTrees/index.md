# ConversationTrees

Action to retrieve `ConversationTree` of multiple casts in a single structure.

## Functions

| Name                | Description                         |
| ------------------- | ----------------------------------- |
| [`ConversationTrees.get`](/actions/extra/ConversationTrees/get) | Get a [`ConversationTree.ConversationTree`](/api/ConversationTree/types#conversationtree) by a given root [`CastId.CastId`](/api/CastId/types#castid). |
| [`ConversationTrees.getByFid`](/actions/extra/ConversationTrees/getByFid) | Get a [`ConversationTree.ConversationTree`](/api/ConversationTree/types#conversationtree) by a given creator `fid`. |

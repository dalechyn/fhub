# Watch

Actions related to real-time updates from Hubs.

## Functions

| Name                | Description                         |
| ------------------- | ----------------------------------- |
| [`Watch.watchCasts`](/actions/watch/Watch/watchCasts) | Creates an `AsyncGenerator` subscription over all merged [`Cast.Cast`](/api/Cast/types#cast)s. |
| [`Watch.watchCastsCompliantToRegexp`](/actions/watch/Watch/watchCastsCompliantToRegexp) | Creates an `AsyncGenerator` subscription over all merged [`Cast.Cast`](/api/Cast/types#cast)s, compliant to a specific `RegExp`. |
| [`Watch.watchCastsMentioningFid`](/actions/watch/Watch/watchCastsMentioningFid) | Creates an `AsyncGenerator` subscription over all merged [`Cast.Cast`](/api/Cast/types#cast)s, mentioning a specific `fid`. |
| [`Watch.watchCastsMentioningUsername`](/actions/watch/Watch/watchCastsMentioningUsername) | Creates an `AsyncGenerator` subscription over all merged [`Cast.Cast`](/api/Cast/types#cast)s, mentioning a specific `username`. |
